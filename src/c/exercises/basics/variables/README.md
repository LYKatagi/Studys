# Variables

## Description

In this exercise, you will practice declaring and using variables in C.

Implement the following functions:

- `get_number()` — return an integer.
- `get_decimal()` — return a floating-point number.
- `get_letter()` — return a character.

## Goal

Practice the basic C types:

- `int`
- `float`
- `char`

## Example

```c
int number = 42;
float decimal = 3.14f;
char letter = 'A';
