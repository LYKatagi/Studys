# Studys

> Uma plataforma pessoal de exercícios para aprender e praticar programação.

O **Studys** é um projeto inspirado em plataformas como o Exercism, criado para organizar exercícios de programação e permitir que eu pratique diferentes linguagens de forma estruturada.

A ideia é transformar o aprendizado em uma sequência de desafios, começando pelo básico e avançando gradualmente para conceitos mais complexos.

---

## 🎯 Objetivos

- 📚 Organizar exercícios de programação
- 🧠 Praticar lógica de programação
- 💻 Aprender e aperfeiçoar diferentes linguagens
- 🔧 Criar exercícios progressivamente mais difíceis
- 🧪 Testar soluções automaticamente no futuro
- 📈 Acompanhar meu progresso

---

## 🗂️ Linguagens

Atualmente, o foco principal é:

- [C](#c)
- [C++](#c-1)
